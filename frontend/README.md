# Frontend DepoRed

Angular 21. Consulta las instrucciones completas en [el README principal](../README.md).

- `npm ci`: instala las dependencias del lockfile.
- `npm start`: servidor local en 127.0.0.1:4200 con proxy hacia la API en el puerto 5080.
- `npm run build`: compilación de producción en dist/depored-web/browser.

Tipografías variables autoalojadas (DM Sans y Manrope), sin solicitudes a Google Fonts. La autorización efectiva se verifica en la API. Las pruebas HTTP, contables y de roles se encuentran en ../tests/integration.mjs.
